# 성장 언어 규칙 (목표·평가 문장 작성법)

학생을 고정된 수준에 두지 않고, **지금 할 수 있는 것과 다음에 성장할 방향**이 문장에 담기게 쓴다.
목표·성공 기준·성장 단계·교사 대응·활동지 안내 문구 모두에 적용한다.

## 1. 학습목표: 지식·기능·태도 세 영역

| 영역 | 문장 틀 | 예시 (6학년 실과, 가상) |
|---|---|---|
| 지식 | ~을 알고 설명할 수 있다 | 제철 식재료를 고르는 까닭을 알고 친구에게 설명할 수 있다 |
| 기능 | ~을 사용하여 ~할 수 있다 | 식품 표시를 살펴 건강하고 안전한 식재료를 고를 수 있다 |
| 태도 | ~하려고 노력하며 ~을 실천해 볼 수 있다 | 여러 식재료를 맛보려고 노력하며 골고루 먹기를 실천해 볼 수 있다 |

- 세 영역을 모두 쓰고, 이 차시의 중심 영역(`focus`) 하나를 표시한다.
- 지식·기능은 눈으로 확인할 수 있는 동사로 끝낸다: 설명할 수 있다, 고를 수 있다, 비교할 수 있다, 만들 수 있다, 나타낼 수 있다.
- **끝맺음 금지 동사**: 안다, 이해한다, 깨닫는다, 익힌다, 기른다, 관심을 가진다
- 태도는 시도·과정을 담는다: ~하려고 노력할 수 있다, ~을 실천해 볼 수 있다, ~을 스스로 점검할 수 있다

## 2. 학생용 성공 기준: "할 수 있어요" + "아직이라면"

| 영역 | 성공 기준 | 아직이라면 |
|---|---|---|
| 지식 | 나는 제철 식재료를 고르는 까닭을 설명할 수 있어요 | 교과서 그림을 보며 짝과 한 가지씩 말해 봐요 |

## 3. 교사용 성장 단계 (상·중·하 대신)

| 단계 | 뜻 |
|---|---|
| 깊어지는 중 | 목표를 넘어 넓히고 있음 |
| 해내는 중 | 목표에 도달함 |
| 시작하는 중 | 목표를 향해 출발함 |

**문장 공식**: `현재 할 수 있는 것` + `다음에 성장할 수 있는 방향` (+ 필요한 도움)

- 깊어지는 중: "식품 표시를 근거로 식재료를 고르고 까닭을 설명하며, 가족의 장보기에 적용해 보면 더 넓어질 수 있음"
- 해내는 중: "식품 표시를 살펴 알맞은 식재료를 고름. 고른 까닭을 함께 말해 보면 더 깊어질 수 있음"
- 시작하는 중: "식품 표시에서 유통기한을 찾아보고 있음. 확인 순서 카드가 있으면 알맞은 식재료 고르기에 다가갈 수 있음"

## 4. 바꿔 쓰기 표 (check.py 금지어 목록과 같음)

| 쓰지 않기 | 바꿔 쓰기 |
|---|---|
| 못한다, 못함 | 아직 ~하는 중이다 |
| 부족하다, 부족함 | ~에 다가가고 있다 |
| 미흡하다, 미흡함 | ~을 함께하면 성장할 수 있다 |
| 하 수준, 하위권, 낮은 학생 | 시작하는 중인 학생 |
| 이해하지 못함 | ~ 부분을 이해해 가는 중임 |
| 지도가 필요함 | ~을 함께하면 성장할 수 있음 |
| 오답, 틀렸다 (학생에게 보이는 곳) | 다시 생각해 볼 답 |
