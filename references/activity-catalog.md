# 활동 카탈로그

4단계에서 활동을 고를 때 쓰는 목록. 교사 반응이 좋았던 활동과 거절된 방식을 함께 적는다.
활동을 넣을 때는 반드시 **어떤 평가 증거를 만들어 내는지** 적는다.

## 검증된 활동

| 활동 | 맞는 흐름 | 만드는 증거 | 핵심 규칙 |
|---|---|---|---|
| 시뮬레이션·타이쿤 (재료 고르기 → 결과 보기 → 점수 평가) | C | 선택 근거 설명, 결과 화면 | 학생이 직접 고르고 결과를 본다. 결과 화면을 캡처해 패들렛에 공유. 백엔드 없음 |
| 추리 미스터리 (사건 파일 → 단서 하나씩 → 모둠 추론) | A, C | 모둠 추론 활동지, 근거 문장 | 상황 설명 필수. **화면이 대신 용의자를 지우지 않는다.** 단서 5개, 마지막에 정답·해설 |
| 협동 탈출게임 (문 4개, 문마다 다른 방식) | A | 단계별 해결 기록 | **시간 제한 없음**, 모둠 협력 |
| 스웜 게임 (움직이는 카드 세기 → 문장 고르기) | A | 활동지 기록 | 화면 가장자리에서 등장, 한 방향 직진, 속도 다양, 비틀비틀, 한 번만 지나감, 멈춤 버튼 |
| 단원 도입 빙고 (초성 퀴즈) | A (단원 첫 차시) | 빙고 활동지 | `danwon-dowip-bingo` 스킬 사용. 답은 교과서 쪽과 대조 |
| OX 퀴즈 (사진·이모지 비교) | A | 힌지 질문 응답 | 비교 대상은 화면의 50% 이상 크기 |
| 단계 카드 순서 맞히기 | B | 순서 설명 | 실습 시범 직후 |
| 갈틱폰식 그리기·맞히기 복습 | A (정리) | 그림·설명 | 단원 복습 차시 |
| 사진 탐정 (확대 사진 두 장 비교 → 짝에게 다른 점 말하기) | A | 짝 설명(관찰 평가) | 비교 질문 2개를 사진 아래에 둔다. 실물 만지기 대신 쓰는 기본 방식 (6학년 실과 10차시 직물·편물) |
| 사진 카드 모둠 토의 | A, C | 모둠 발표 | 기기 조사 대신 슬라이드의 사진 카드를 보고 토의 (6학년 실과 11차시 재활용 생활용품) |

## 거절된 방식 (쓰지 않기)

- 모둠 기기 검색·패들렛 조사 (교사가 뺌 → 사진 카드로 대체)
- 실물을 만져 보는 활동을 교실 조건 확인 없이 넣기 (교사: "직접 만지지는 못해" → 사진·영상 비교)

- 글자만 있는 퀴즈를 장르만 바꾼 것 (서바이벌, 사목 게임, 카운트다운 폭탄 등)
- 시간 압박 게임
- 화면이 학생 대신 추론·판단을 해 주는 것
- 실제 노래 없이 가사만 화면에 쓰는 노래 활동 (저작권 있는 가사는 어떤 경우에도 화면 텍스트로 쓰지 않음)

## 화면용 + 활동지 짝

모둠 활동·쓰기 활동은 **화면용 HTML**(한 번에 한 문항, 큰 글씨, 교사 정답 공개 버튼)과
**활동지 HTML**(번호 맞춘 빈칸, Ctrl+P 인쇄, 마지막 쪽 교사용 정답)을 짝으로 만든다.
