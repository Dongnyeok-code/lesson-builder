# 디자인 시스템

기본 디자인은 **editorial**(`templates/editorial.html` + `editorial.js`)이다. 교사가 보낸 참고 자료(5학년 실과 '수송 수단의 구성 요소' PPT)를 기준으로 만들었다.
예전 둥근 카드형 디자인은 `meta.design: "classic"`으로만 쓴다.

## editorial 규칙
- 1600×900(16:9) 고정 화면을 창·전체화면 크기에 맞춰 통째로 확대·축소한다. 그래서 일반 창과 전체화면의 배치가 같다.
- 글꼴은 Pretendard 하나(본문 500, 제목 700). **이모지·그림자·둥근 카드·그라데이션을 쓰지 않는다.** 이모지는 자동으로 지워진다.
- 배경: 크림 #FAF6EE / 민트 #E9F5E6 / 하늘 #DDF1FB / 분홍 #FCE6EF / 흰색. 생각 열기·영상·마무리는 남색 #16324F 전체 화면.
- 상단 8px 색 띠, 왼쪽 위 작은 단원·차시 표시, 왼쪽 정렬 제목(59px), 하단 왼쪽 교과서 쪽수, 하단 오른쪽 쪽 번호.
- 강조색: 파랑 #2E73B8, 초록 #4DAA45, 분홍 #EB3E86, 노랑 #F7C948. **개념마다 색을 고정**한다 → `meta.theme.concepts`에 {"직물":"blue","편물":"pink"}처럼 적는다.
- **단원 컨셉 색**: 레이아웃은 그대로 두고 `meta.theme.palette`로 색만 단원 주제에 맞게 바꾼다.
  역할 이름: cream·mint·sky·pinkbg(배경 4종), navy(강조 화면), blue·green·pink·yellow(개념 강조 4색), ink(글자).
  예) 의생활·뜨개질 → 따뜻한 크림·세이지·테라코타·머스터드 / 식생활 → 쌀·채소·고추색 / 로봇·정보 → 남색·청록·회색.
  배경과 글자의 명암 대비는 유지한다(연한 배경 + 진한 글자).
- 결론·기억할 문장은 하단 색 띠(`pill`)로 둔다.
- 낱말 알기: 한자어는 큰 한자 + 한글 + 글자별 뜻, 순우리말·영어는 큰 낱말 + 유래.
- 교과서·지도서 그림은 크게, 캡션은 작게. 표지는 왼쪽 남색 제목 + 오른쪽 대표 그림.
- 한국어 줄바꿈은 단어 단위(word-break: keep-all).
- 글자 크기는 slide-style.md 7절을 따른다 (교사 요청으로 키움: 제목 59px, 본문 52px, 카드 설명 46px, 그림 옆 설명 44px, 낱말 뜻 54px). 템플릿 맨 아래 '가독성 강화' 블록에 모아 두었다.

## 인쇄용 활동지
- A4, Ctrl+P로 바로 인쇄. 실제 `<table>`과 `break-inside:avoid`. 상단 이름 칸·학습목표, 하단 자기 점검, 교사용 정답은 마지막 쪽.

## 그림이 들어가는 자리
- 카드: `cards[].img` → 카드 위 300px 그림. 한 슬라이드의 카드는 모두 그림이 있거나 모두 없게 한다.
- 순서 빈칸: `fillblank.imgs[]` → 칸마다 그림.
- 그림+설명: `stage` → 왼쪽 그림(화면 48%), 오른쪽 태그·설명.
- 그림은 build.py가 1100px 이하 WebP로 줄여 넣는다 (2차시 묶음 약 2MB).
