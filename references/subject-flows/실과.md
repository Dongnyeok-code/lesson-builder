# 실과 수업 흐름 틀 (2022 개정)

실과 교과 역량: **생활 자립, 관계 형성, 실천적 문제 해결**.
차시의 성격을 먼저 셋 중 하나로 정하고 그 흐름을 따른다. 40분 기준이며 묶음 차시는 전개를 늘린다.

## A. 개념 탐색형 (이론 위주 차시)

| 단계 | 시간 | 하는 일 |
|---|---|---|
| 도입 | 5분 | 생활 장면으로 동기 유발 → 진단 질문(선수학습) → 학습목표·성공 기준 확인 |
| 전개 1 | 12분 | 교과서 자료 탐색 (그림·사례 관찰, 짝 토의) |
| 전개 2 | 15분 | 개념 정리 활동 (분류·비교·게임) → **힌지 질문** |
| 정리 | 8분 | 생활 적용 한 가지 정하기 → 출구표 → 자기 점검 → 차시 예고 |

## B. 실습형 (만들기·조리·관리 차시)

| 단계 | 시간 | 하는 일 |
|---|---|---|
| 도입 | 5분 | 완성 예시 보여 주기 → 진단 질문 → 학습목표·성공 기준 확인 |
| 안전 약속 | 3분 | 도구·재료 안전 수칙 확인 (실습 차시 필수) |
| 시범 | 7분 | 교사 시범 또는 영상 → 단계 카드로 순서 확인 → **힌지 질문** |
| 실습 | 18분 | 모둠·개인 실습, 교사는 과정 관찰(성장 단계표 기록) |
| 정리 | 7분 | 결과 나누기 → 출구표 → 자기 점검 → 정리정돈 |

## C. 문제 해결형 (프로젝트·시뮬레이션 차시)

| 단계 | 시간 | 하는 일 |
|---|---|---|
| 도입 | 5분 | 생활 속 문제 상황 제시 → 학습목표 확인 |
| 문제 확인 | 5분 | 문제와 조건 정리 |
| 해결 방안 탐색 | 10분 | 교과서 근거로 여러 방안 비교 → **힌지 질문** |
| 실행 | 13분 | 시뮬레이션·설계·만들기로 실행 |
| 평가·공유 | 7분 | 결과 공유(패들렛 등) → 출구표 → 자기 점검 |

## 공통 규칙

- 실습·조리·도구 사용이 있으면 B형의 "안전 약속"을 반드시 넣고, 안전 관련 과정 관찰을 평가 증거에 포함한다.
- 모든 활동은 교과서 쪽 근거가 있어야 한다.
- 정리는 항상 출구표 + 자기 점검으로 끝낸다.
