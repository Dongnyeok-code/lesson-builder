# 화면용 수업자료(PPT형 HTML) 스타일 규칙 — 교사 지정

이 규칙은 design-system.md보다 우선한다. 교사가 고쳐 달라고 한 내용은 여기에 쌓는다.

## 1. 분량과 품질
- 차시별 **최소 30장, 위로는 제한 없음**. 장수가 많다는 것은 더 자세히 설명한다는 뜻이다 (교사 확인). 최선의 품질로 만든다.
- 숫자 채우기용 슬라이드는 넣지 않는다. **알짜만** 남긴다.
  - 넣지 않는 예: 내용 없는 "생각해 봐요" 반복, 같은 내용을 다시 말하는 요약, 의미 없는 간지·장식 슬라이드
  - 30장에 못 미치면 채우기용 장이 아니라 **적용 연습(다른 사례에 같은 원리 적용), 사례·사진, 용어 설명, 본문 캡처**처럼 이해를 돕는 장을 더한다.

## 2. 구성과 이동
- **차시마다 상단 탭**으로 오간다 (예: [10차시] [11차시]). 키보드 숫자 1·2·3으로도 전환.
- 각 차시 안에서는 **이전/다음 버튼**과 ←/→·스페이스로 넘긴다. "현재/전체" 표시.
- 전체화면 버튼. 전체화면에서는 탭·버튼을 숨긴다.

## 3. 글꼴
- 제목: **Pretendard Bold**, 본문: **Pretendard Medium** — 교사가 보낸 참고 PPT처럼 모던하게
- 이모지·장식 카드 없이 색 띠·여백·타이포·실제 그림으로 디자인한다 ("AI 티" 금지)

## 4. 그림·영상
1. 교과서·지도서 그림과 지도서 안내 영상을 **먼저** 넣는다 (쪽 번호 표시).
2. 없으면 검색해서 넣는다 (media-policy.md). **그림이 없다고 글자만 두지 않는다.**
3. 설명을 보강할 영상은 유튜브에서 찾아 넣는다 (임베드 + "유튜브에서 열기" 링크).
4. 교사가 영상 링크를 주면 그 영상으로 바꾸고 슬라이드 제목도 영상 내용에 맞게 고친다.
5. 조사·사례 슬라이드(로봇 사례 등)는 **사례마다 1~4분짜리 영상**을 바로 뒤에 붙인다 (뉴스·공식 채널 우선, 수술처럼 장면이 센 주제는 아이 눈높이 영상).
6. 사진은 아이들이 보기에 어색하거나 무섭지 않은 것을 고른다 (사람을 닮은 로봇은 특히 확인).
7. 사례를 소개한 뒤에는 **장점·단점(한계)**을 생각해 보는 슬라이드를 둔다 (예: 사람 대신 산업용 로봇이 일하면? / 아직 로봇이 어려워하는 것).

## 5. 초등학생 눈높이
- 모든 설명은 초등학생이 이해할 수 있는 말로 쓰고, **생활 속 예시**를 함께 든다.
- 어려운 **한자어·영어 단어**는 처음 나오기 전에 **별도 "낱말 알기" 슬라이드** (낱말 → 쉬운 뜻 → 생활 예시).
- 교과서의 **과정·단계 표는 단계마다 한 장씩** 따로 설명한다 (예: 계획하기 / 준비하기 / 본뜨기 / 마름질하기 / 바느질하기 / 정리 및 평가하기).
  각 장 = 단계 그림 + "교과서" 설명 + "더 알아보기" 보충.
- 한 슬라이드에는 한 가지 생각만 담고, 글은 짧게 쓴다.

## 6. 단원 컨셉
- 레이아웃은 그대로 두고 **색만 단원 주제에 맞게** `meta.theme.palette`로 바꾼다 (design-system.md).
  - 예: 의생활·뜨개질 → 크림·세이지·테라코타·머스터드 / 식생활 → 쌀·채소·고추색 / 로봇·정보 → 남색·청록·회색
- 컨셉이 바뀌어도 글꼴과 가독성 규칙은 유지한다.

## 7. 뒷자리 가독성
- **교실 맨 뒷자리 학생이 읽을 수 있는 크기**가 기준이다. 1600×900 화면 기준 최소 크기:
  - 슬라이드 제목 59px, 표지 제목 73px
  - 본문(설명 글) 52px, 카드 설명 46px, 그림 옆 설명 44px, 카드 제목 54px, 힌지 선택지 42px, 출구표 50px, 자기 점검 44px
  - 낱말 알기: 한자 165px, 뜻 54px, 예시 46px
  - 캡션 30px, 쪽 표시 22px
- 글자와 배경의 명암 대비를 충분히 둔다 (연한 회색 글씨, 사진 위 글씨 금지).
- 한 슬라이드의 본문은 **3~4줄 이내**. 넘치면 슬라이드를 나눈다.
- 핵심 낱말은 색이나 굵기로 강조하되, 한 슬라이드에 2~3개만.

## 8. 교실 조건
- 학생이 실물을 만지거나 기기로 조사하는 활동은 교사 확인 전에는 넣지 않는다. 기본은 **확대 사진·영상 비교**.

## 9. 7단원 테스트에서 생긴 규칙
- **교과서 본문 먼저**: 차시마다 본문 캡처 슬라이드를 넣고 중요한 문구에 옅은 형광펜, 왼쪽 여백에 색연필 별표를 단다.
- **비교 목록은 번호 + 옅은 상자**로 쓴다 (좋은 점/걱정되는 점, 장점/단점).
- **역량 활동 앞에는 소제목 슬라이드**를 두고 다음 장에서 무엇을 할지 알려 준다 (활동 설명 장 대신).
- **사람과 로봇처럼 짝을 비교하는 그림**은 교과서 그림처럼 양옆에 두고, 누를 때마다 한 줄씩 나오게 한다.
- **예시 답안은 바로 보여 주지 않는다**: '예시 답안 보기'를 눌러야 나오게 한다 (교과서에 인쇄된 첫 예시는 그대로 보여도 됨).
- 지난 시간 복습은 **지난 시간에 배운 내용만** 다룬다. 이번 시간에 처음 배우는 개념을 복습처럼 내지 않는다.
- 학생들이 잘 아는 친근한 사례(로봇 물고기, 로봇 개 등)를 조사 사례에 우선 넣는다. 회사의 최신 대표 로봇을 고를 때는 최근 기사로 확인한다.
- 예시 글(가상 일기 등)은 학생이 재미있어할 장면(이름 붙인 로봇, 작은 실수, 학교생활)을 넣어 쓴다.
- 화살표 기호(↔ 등)는 그림 글자로 지워질 수 있으니 제목에 쓰지 않는다.
