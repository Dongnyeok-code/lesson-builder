# 가상 예시: 생활 속 로봇 1차시

**실제 교과서가 아닌, 형식을 보여 주려고 지어낸 예시**입니다. 교과서 쪽 번호(10~11쪽)와 본문, 지도서 내용은 모두 가상이고, 그림 3장은 이 저장소용으로 직접 그린 SVG입니다.
성취기준 [6실04-04] 원문만 실제 교육부 고시에서 가져왔습니다 (고시는 저작권법 제7조에 따라 보호받지 않는 저작물).

| 파일 | 단계 | 내용 |
|---|---|---|
| input.json | 0 | 학년·교과·단원·차시·쪽 범위 |
| curriculum.json | 1 | 성취기준 원문과 교차 검증 결과, 지식·기능·태도 요소 |
| assessment.json | 2 | 학습목표, 평가 증거, 성공 기준, 성장 단계, 확인 질문 3개, 자기 점검 |
| evidence.json | 3 | 교과서·지도서 근거(모든 항목에 쪽 번호), 그림 설명 |
| flow.json | 4 | 교사 승인된 수업 흐름과 슬라이드 계획 |
| lesson.json | 5~6 | 화면용·활동지·수업안을 만드는 단일 원본 |
| 1차시_화면용.html 외 | 6~8 | build.py 결과물 (브라우저로 열어 보세요) |
| qa-report.md | 7 | check.py 결과 |

예시라서 20장으로 짧게 만들었습니다. 그래서 검사에서 경고 2개(30장 미만, 교과서 그림 6장 미만)가 나옵니다. 실제 차시는 30장 이상이고, 교과서 본문 캡처(`textbook`)와 영상(`video`) 슬라이드도 들어갑니다.

다시 만들어 보기 (스킬 폴더에서):
```
python3 scripts/build.py examples/sample_robot_1/lesson.json
python3 scripts/check.py examples/sample_robot_1
```
